# Vasishtan K — VFX Portfolio

A single-file cinematic portfolio website.

## Free deployment
### GitHub Pages
1. Create a GitHub repository, e.g. `vasishtan-vfx`.
2. Upload `index.html`.
3. Repository Settings → Pages → Deploy from branch → `main` / root.
4. GitHub will provide a free `github.io` address.

### Cloudflare Pages
Import the GitHub repository in Cloudflare Pages. No build command is required; the output directory is the repository root.

## Notes
- Three.js is loaded from a public CDN.
- The 3D scene is procedural, so no paid 3D assets are required.
- Replace/add showreel, before/after shots and a professional portrait when available.
